# MadMamba Architecture Decision Records

The R0-ADR-002 baseline contains the minimum architectural decisions required before implementation proceeds:

- [ADR-0001](ADR-0001-per-interpreter-runtime.md) — per-interpreter runtime ownership.
- [ADR-0002](ADR-0002-sys-monitoring-policy.md) — sys.monitoring event and tool-ID policy.
- [ADR-0003](ADR-0003-jsonl-bundle.md) — versioned bundle and JSONL record model.
- [ADR-0004](ADR-0004-local-first-viewer.md) — local-first, offline viewer boundary.
- [ADR-0005](ADR-0005-experimental-injection-separation.md) — stable/experimental injection separation.

ADRs are immutable decision records after acceptance except for factual corrections or explicit supersession metadata. A superseding decision must reference the prior ADR and the prior ADR must identify its superseder.

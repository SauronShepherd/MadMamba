## Privacy and security

- The validator refuses repository-relative paths that escape the repository root.
- The test suite scans repository text files for explicit secret/payload canaries.
- No network access, environment-value interpolation, source loading, or application payload inspection is introduced by this task.

## Known limitations / unavailable lanes

- This task does not execute application code, so semantic parity is not applicable under the global task contract.
- Free-threaded, multi-interpreter, Spark, Arrow, attach, and runtime performance lanes are not applicable to this file-only traceability validator.
- Full cross-platform CI cannot be claimed until repository CI exists; this first R0 task bootstraps traceability before CI infrastructure is introduced by later roadmap work.
